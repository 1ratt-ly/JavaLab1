# Лабораторна робота №1

**Тема:** Сучасні можливості Java та Data-Oriented Programming  
**Група:** ІА-43

## Мета роботи

Навчитися моделювати незмінні дані за допомогою Records та Sealed Types, розділяти дані й алгоритми, реалізовувати вичерпну бізнес-логіку через Switch Expressions та Pattern Matching, а також використовувати Text Blocks.

## Варіант

Порядковий номер у списку групи: 3.

Розрахунок: `V = N mod 3 = 3 mod 3 = 0`

Варіант: 0 - система управління замовленнями

## Опис проєкту

Програма моделює чотири статуси замовлення: очікування обробки, оплату, відправлення та скасування. Клас OrderProcessor формує текстовий опис статусу. Дані представлені незмінними records, об'єднаними sealed-інтерфейсом OrderStatus.

## Тести

Для автоматичного тестування використано JUnit 5

- Створення об'ктів Paid, Shipped і Cancelled із коректними даними
- Відхилення null, порожніх і пробільних рядків в обов'язкових текстових полях
- Відхилення відсутньої, нульової та від’ємної суми оплати
- Допустимість малої додатної суми оплати
- Відхилення відсутньої дати відправлення
- Формування текстового опису для всіх чотирьох статусів замовлення
- Викидання IllegalArgumentException при передаванні null в обробник

Усі тести пройшли успішно

## Запуск тестів

Відкрити термінал у корені проєкту і виконати ```mvn clean test```
